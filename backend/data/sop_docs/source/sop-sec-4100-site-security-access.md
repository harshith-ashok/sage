# SOP-SEC-4100: Site Security and Access Control

**Document owner:** Security Department
**Effective date:** 2024-01-12
**Review cycle:** 24 months

## Section 1. Purpose and Scope

Governs badge issuance, visitor management, and restricted-area access control for the site, consistent with the facility's confidential/government-sensitive work classification.

## Section 2. Badge Issuance

Clause 2.1 — Personnel badges are issued only after background screening appropriate to the individual's required access level is complete; a badge is deactivated immediately upon termination or role change removing the need for prior access.

## Section 3. Visitor Management

Clause 3.1 — Every visitor is logged (name, host, purpose, time in/out) and issued a visibly distinct visitor badge; visitors are escorted at all times within restricted areas and are prohibited from restricted areas entirely unless the host has pre-authorized specific access.

## Section 4. Restricted Area Access

Clause 4.1 — Restricted areas (control rooms, server rooms, areas handling controlled or classified information) require access-list authorization beyond general site badge access; access lists are reviewed quarterly and immediately upon personnel role change.

Clause 4.2 — Tailgating (entering on another person's badge access without individually badging) through a restricted area access point is prohibited; any employee observing tailgating shall report it to Security.

## Section 5. Incident Reporting

Clause 5.1 — A lost or stolen badge is reported to Security immediately for deactivation; a suspected unauthorized access attempt is reported the same day.

## Section 6. Records

Clause 6.1 — Access logs and visitor logs are filed to the Security Department File and retained for 2 years, or longer where required by the site's specific government contract terms.
