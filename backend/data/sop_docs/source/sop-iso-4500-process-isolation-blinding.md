# SOP-ISO-4500: Process Isolation and Blinding

**Document owner:** Process Safety Department
**Effective date:** 2024-04-25
**Review cycle:** 24 months

## Section 1. Purpose and Scope

Governs positive isolation (blinds, spectacle blinds, double block-and-bleed) of process piping for maintenance, distinct from electrical/mechanical lockout under SOP-LOTO-400.

## Section 2. Isolation Method Selection

Clause 2.1 — A single block valve is not acceptable positive isolation for entry or hot work on a line that has contained a hazardous material; a physical blind, spectacle blind (rotated to the blind position), or verified double block-and-bleed is required.

Clause 2.2 — Double block-and-bleed is only acceptable positive isolation where both block valves are verified leak-tight by observing the bleed valve during the isolation period, not assumed from valve position alone.

## Section 3. Blind List

Clause 3.1 — Every isolation for a permit-required confined space entry or hot work on process piping requires a documented blind list identifying each isolation point, its type, and installer, verified against the piping isolation drawing before work begins.

## Section 4. Installation and Removal Verification

Clause 4.1 — Blind installation is verified by a second qualified person (independent check) before the permit authorizing entry/hot work is signed; removal at job completion is verified the same way before the line is returned to service.

## Section 5. Records

Clause 5.1 — Blind lists and installation/removal verifications are filed to the Process Safety File and retained for 3 years.
