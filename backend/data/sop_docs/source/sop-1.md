## 1. Relief Valve Set-Pressure Verification

**To:** Process Safety Department, Operations
**From:** R. Delgado, Process Safety Engineer
**Date:** 2026-06-09
**Subject:** PSV-4410 — Set Pressure Verification Result (per SOP-PS-210 Clause 3.5)

### Background

Per SOP-PS-210 Section 3, Clause 3.5, all spring-loaded relief valves in
overpressure-critical service require bench testing and set-pressure
verification at each turnaround interval, or sooner if a process
deviation triggers the Clause 3.7 unscheduled-test threshold. PSV-4410,
protecting the V-2201 overhead system, was pulled and bench tested this
cycle following a recorded upstream pressure excursion.

### Assessment Result

The verified set pressure for PSV-4410 is **148 psig**, within the
allowable ±3% tolerance of the nameplate set point of 150 psig. No
seat leakage was observed at 90% of set pressure during the
as-found test. This result confirms the valve remains fit for
continued service without adjustment.

Any future as-found test result outside the ±3% tolerance band shall
require valve removal, re-set, and a documented root-cause review per
SOP-PS-210 Clause 3.8 before return to service.

### Distribution

Filed to the Pressure Relief Device File per SOP-PS-210 Clause 5.2.
Retain until the next scheduled test interval plus 5 years.
